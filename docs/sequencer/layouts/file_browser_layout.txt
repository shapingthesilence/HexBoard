SEQUENCER FILE BROWSER LAYOUT

The browser title changes with the current browser mode and folder.

Examples:

  Load:Sequences
  Save:Basslines
  Folder:Ideas
  RenDel:Drums

Common structure:

  [top action, if used by this mode]
  [secondary top action, if used by this mode]
  ..
  ^ more ^    [only when earlier pages exist]
  entry 1
  entry 2
  entry 3
  entry 4
  entry 5
  entry 6
  entry 7
  entry 8
  v more v    [only when later pages exist]

Mode-specific top actions:

Save New mode:

  Save Here
  New Folder
  ..
  [folders and files]

Create Folder mode:

  Create Here
  ..
  [folders only]

Rename or Delete mode:

  This Folder...   [hidden at /Sequences]
  ..
  [folders and files]

  Selecting a folder enters it.
  Selecting a file opens a separate Rename/Delete/Cancel action page.
  Selecting This Folder... opens that same action page for the current folder.

Load mode:

  ..
  [folders and files]

Notes:

- Folders can be entered by selecting them.
- Files can be loaded or opened in the Rename/Delete/Cancel action page
  depending on the current mode.
- Rename or Delete keeps folder navigation in the browser and only opens its
  action page for files or the current-folder target row.
- The root folder is /Sequences.
- Turning the encoder past the first or last real file row changes page.

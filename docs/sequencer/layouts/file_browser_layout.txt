SEQUENCER FILE BROWSER LAYOUT

The browser uses a two-line header. The first line names the current action and
the second line shows the current folder path.

Examples:

  Load Sequence
  /Sequences

  Save Sequence
  /Sequences/Basslines

  Create Folder
  /Sequences/Ideas

  Rename/Delete
  .../Sessions/Drums

When a path exceeds the 120-pixel header text area, complete leading folder
levels collapse to `...`; the nearest parent and current folder remain visible.
Only a current folder name that is itself too wide is cropped within the name.

Common structure:

  [top action, if used by this mode]
  [secondary top action, if used by this mode]
  ..
  entry 1
  entry 2
  entry 3
  entry 4
  entry 5
  entry 6
  entry 7
  entry 8
  entry 9
  entry 10

Mode-specific top actions:

Save New mode:

  Save Here
  New Folder
  ..
  [folders and files]

Create Folder mode:

  Create Here
  ..
  [folders only]

Rename or Delete mode:

  This Folder...   [hidden at /Sequences]
  ..
  [folders and files]

  Selecting a folder enters it.
  Selecting a file opens a separate Rename/Delete/Cancel action page.
  Selecting This Folder... opens that same action page for the current folder.

Load mode:

  ..
  [folders and files]

Notes:

- Folders can be entered by selecting them.
- Files can be loaded or opened in the Rename/Delete/Cancel action page
  depending on the current mode.
- Rename or Delete keeps folder navigation in the browser and only opens its
  action page for files or the current-folder target row.
- The root folder is /Sequences.
- The two-line, 18-pixel header leaves room for 11 list rows, including the
  always-present back row. Turning through the list advances to the next or
  previous 11-row page.

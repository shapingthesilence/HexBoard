DELETE CONFIRMATION LAYOUT

Title:

  Delete File?
  or
  Delete Folder?

Current OLED layout:

  Delete file:
  [file name]
  This cannot be
  undone.
  Yes, Delete
  Cancel

  or

  Delete folder:
  [folder name]
  This cannot be
  undone.
  Yes, Delete
  Cancel

Interaction:

- This page opens from File Browser delete actions.
- The target name is shown before anything is removed.
- Turning the encoder moves between `Yes, Delete` and `Cancel`.
- Pressing the encoder on `Yes, Delete` performs the delete.
- Pressing the encoder on `Cancel` returns to the File Browser without deleting.

Notes:

- Folder deletion remains recursive after confirmation.
- The page title changes between file and folder deletion.

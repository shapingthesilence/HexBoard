SEQUENCER ALWAYS-ON SPECIAL KEYS

This file describes the real Sequencer-mode key grouping more accurately.

Important physical note:

- The HexBoard has a separate command-button column on the side.
- Those command buttons are not part of the normal 8-key playable row.

Sequencer step area:

- Row 1 playable keys: steps 1-8
- Row 2 playable keys: steps 9-16
- Row 3 playable keys: steps 17-24
- Row 4 playable keys: steps 25-32

Always-on special keys:

- First-row last button:
  Play/Stop
  - short press toggles transport
  - 2-second hold shows the performance monitor while held

- Second-row 2nd-to-last button:
  Overview
  - pages through the packed overview screen
  - stays lit white while idle
  - becomes brighter white while the overview is open

- Second-row last button:
  Blue action key
  - short press: undo selected step back to the state it had when selected
  - 1-second hold: clear selected step

- Third-row last button:
  Step tools picker
  - opens the key-driven step tools overlay for the selected step
  - current tool entries: Len, Vel, Oct+, Oct-, Prob, Tie, Copy
  - while open, those tool entries move to the lower rows so the top 4 step
    rows remain visible and can switch the current step
  - stays lit white while idle
  - becomes brighter white while the tools picker is open

Current always-on special-key candidate:

- fourth-row command button

Practical mental model:

- The first 8 playable keys of each sequencer row are the step pads.
- The separate side command buttons are where the always-on sequencer utility keys live.

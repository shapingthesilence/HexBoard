SEQUENCER STEP TOOLS PICKER

This screen appears when the last button on the third row is pressed while a
step is selected.

Purpose:

- give quick key-based access to step editing tools without adding more items
  to the main Sequencer menu

Current OLED layout:

  Tools #13
  L 150% V 96 P 75%
  C3 E3 G3
  B3 D4 F4
  Len Vel Oct+ Oct-
  Prob Tie Copy
  Cancel/Finished

Current active tool keys:

- sixth-row key 1: Len
- sixth-row key 2: Vel
- sixth-row key 3: Oct+
- sixth-row key 4: Oct-
- seventh-row key 1: Prob
- seventh-row key 2: Tie
- seventh-row key 3: Copy
- lower CANCEL key two rows below its old position: exits the picker

Current behavior:

- the top 4 sequencer step rows stay lit while the picker is open
- tapping another step pad switches the selected step and keeps the picker open
- Len opens the exact length screen for the selected step
- Vel opens the exact velocity screen for the selected step
- Prob opens the exact probability screen for the selected step
- Oct+ transposes the selected step up 1 current tuning cycle and stays in the picker
- Oct- transposes the selected step down 1 current tuning cycle and stays in the picker
- Tie toggles the selected step's Tie flag and stays in the picker
- Copy opens destination-step selection and copies notes, length, velocity,
  probability, and Tie into the tapped destination step, then returns to the
  tools picker on that destination step
- Step note labels follow the current tuning naming style.
- The note area stays on one line when the labels fit and wraps only when
  needed.
- If the selected step is tied, the note area shows `T` instead of note labels.

LED behavior while the picker is open:

- tool keys are blue
- CANCEL is blue
- the normal step and transport LEDs remain visible above the tool rows

Display behavior:

- this overlay keeps the display awake while it is open

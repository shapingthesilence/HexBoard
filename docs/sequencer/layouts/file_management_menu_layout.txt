FILE MANAGEMENT MENU LAYOUT

Title:

  File Management

Menu order:

  Rename or Delete
  Create Folder
  USB Backup

Notes:

- This submenu exists to keep the main Sequencer menu less cluttered.
- Rename or Delete is the board-side rename and delete workflow.
- Rename or Delete opens a combined browser plus a separate action picker.
- Delete from that action picker opens a separate confirmation page before
  anything is removed.
- Create Folder opens a folder-only browser flow.
- USB Backup opens a dedicated status page with Start Session and Stop Session.

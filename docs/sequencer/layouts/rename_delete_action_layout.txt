RENAME OR DELETE ACTION LAYOUT

Title:

  File Action?
  or
  Folder Action?

Current OLED layout:

  File: or Folder:
  [target name]

  Choose action.
  Rename
  Delete
  Cancel

Interaction:

- This page opens from the Rename or Delete browser mode.
- Files open it when selected in the browser.
- `This Folder...` opens it for the current folder.
- Turning the encoder moves between `Rename`, `Delete`, and `Cancel`.
- Pressing the encoder on `Rename` opens the existing naming workflow.
- Pressing the encoder on `Delete` opens the existing delete confirmation page.
- Pressing the encoder on `Cancel` returns to the browser.

Notes:

- The browser selection should remain as close as practical when returning.
- This page does not perform deletion directly.
